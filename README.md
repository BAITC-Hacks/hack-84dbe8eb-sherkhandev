# HackAlem AI

Минимальный браузерный прототип чата-консультанта для магазина электротоваров.

## Запуск

Из этой папки выполните:

```bash
python3 -m http.server 8000
```

Откройте в браузере [http://localhost:8000](http://localhost:8000).

## Что работает

- русскоязычный адаптивный интерфейс HackAlem AI;
- поиск 6 тестовых товаров по артикулу или названию;
- характеристики, цена в тенге и остаток;
- предложение аналога для товара EL-104, которого нет в наличии;
- демонстрационные ответы про оплату и доставку;
- кнопки с примерами запросов;
- добавление целого положительного количества только после нажатия «Подтвердить добавление»;
- ограничение добавления доступным остатком и защита от повторного подтверждения одного предложения;
- корзина с позициями, общей суммой и сохранением в `localStorage`;
- ссылка «Открыть корзину» после добавления.

Проверка логики Node-тестами:

```bash
node test/app.test.js
```
