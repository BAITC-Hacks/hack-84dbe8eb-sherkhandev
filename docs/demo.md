# Демонстрация участника 3

Интерфейс раздаётся приложением участника 1 с `/`, статические файлы находятся в `web/`. Токен сессии хранится только в памяти вкладки; после перезагрузки создаётся новая сессия. Ссылка `/cart/view/<token>` — только для чтения и имеет TTL.

## Запуск

Из `backend`:

```powershell
$env:CATALOG_MODE='fixture'
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --workers 1 --no-access-log
```

Открыть `http://127.0.0.1:8000/`. Проверены целевые ширины 360 и 1280 px: интерфейс адаптивный, горизонтальная прокрутка не требуется.

## Сценарии

1. Выбрать «Учебный склад», запросить характеристики товара — источник и частичная выборка должны быть обозначены сервером.
2. Запросить сертификат DEMO-001; ссылка ведёт на синтетический учебный документ.
3. Спросить аналог DEMO-002: нулевой остаток исходного товара не превращается в доступность, DEMO-003 показывается с ограничениями.
4. Запросить условия оплаты, доставки и минимальной партии — они помечены демонстрационными.
5. Отправить `DEMO-001`, запросить 2 шт., отдельно подтвердить карточку. Ожидается одна строка, цена 1200.00, сумма 2400.00; повтор подтверждения идемпотентен.

## Проверки

Корзину можно проверить командами `python -m pytest tests/cart -q` и после сборки приложения `python -m pytest tests/integration -q`. Реальную LLM/EKT-проверку нужно отметить отдельно: без `OPENAI_API_KEY` чат честно возвращает `LLM_UNAVAILABLE`, fixture-каталог при этом доступен.

Зависимости интеграции: участник 1 подключает `app.api.cart.router` без prefix, сохраняет `--no-access-log` для секретного пути и не передаёт `cart_url` в LLM/историю; участник 2 предоставляет единственный `backend/data/catalog/fixture.json` и сертификат.
